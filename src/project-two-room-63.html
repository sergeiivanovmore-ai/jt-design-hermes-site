2-комнатная 63 м²: перепланировка в 3К

Из двушки — трёшка для семьи с двумя детьми: визуализации на каждый вариант.

Задача клиента

Перепланировка из 2к в 3к для семьи с двумя детьми, где нужна была отдельная комната для каждого.

Моё решение

  • Присоединение территорий: кухня перенесена на место гардеробной и части коридора (с законным демонтажем старых перегородок).
  • Новая зона — кабинет: на месте бывшей кухни появился кабинет, который по факту выполняет функцию отдельной спальни для подростка.
  • Зонирование гостиной: пространство разделено стеклянной перегородкой на детскую (у окна) и просторную гостиную-столовую (рядом с кухней).
  • Законность: все изменения спроектированы по нормам, чтобы перепланировку можно было узаконить без рисков штрафов.

Результат: вместо тесной двушки — просторная трёшка с изолированной спальней для ребёнка и большой кухней-гостиной.
